# 면담 메모 — 상세 바람장 없이 드론 선원 추정이 되는가 (2026-10-03, 지희)

## 1. 지적 사항과 대응
- 지적: 상세 CFD 바람장을 PF에 직접 쓰는 방식은 바람장을 안다고 가정한 것이고, 현장에서는 며칠짜리 계산을 할 수 없다. (A) 상세 유동장 없이 푸는 방법 또는 (B) 제한된 정보로 상세 유동장을 빠르게 추정하는 방법이 필요.
- 대응: 추정기(PF 전방모델 + 정책 관측의 바람)에 주는 바람 정보를 세 수준으로 두고, **같은 파이프라인·같은 130 에피소드(시작 위치·소스·시간 동일)** 로 비교했다. 진실 데이터(LDM 입자), 성공 판정(σ < 30 m, 오차 < 50 m), 보상, 기준 방법 정의는 그대로다.

| 수준 | 현장에서 필요한 정보 | 전방모델 | 계산 |
|---|---|---|---|
| W0 | 기준 바람 1점(풍속·풍향) | 균일 바람 + 가우시안 플룸 (A안) | 즉시 |
| W1 | 기준 바람 1점 + 건물 지도(GIS) | 건물 주위 질량 보존 포텐셜 유동 → 이류–확산 adjoint (B안의 가장 가벼운 형태; 진단 바람 모델 QUIC-URB·QES-Winds·URock 계열의 단순화) | 1~2 s |
| W2 | 상세 CFD 바람장 | 기존 adjoint (참고 상한) | 며칠 |

## 2. 결과 (2대, 시간 변화 플룸, 관측 가능 12개 소스 120 에피소드; 괄호는 학습에 쓰지 않은 홀드아웃 3개 소스 30 에피소드)

| 방법 | W0 평균 바람 | W1 평균 바람 + 건물 지도 | W2 CFD 바람 |
|---|---|---|---|
| random | 0 % (0) | 0 % (0) | 0 % (0) |
| lawnmower | 2 % (0) | 2 % (0) | 2.5 % (0) |
| greedy-MAP | 9 % (13) | 8 % (13) | 12.5 % (23) |
| GMM-Infotaxis | 11 % (13) | 8 % (13) | 12.5 % (27) |
| **PPO (제안, 해당 수준에서 학습)** | 시드 1 **15 % (23)**, 시드 2 6 % (7) | 시드 1 7 % (3) | 시드 1 14 % (17); 3시드 평균 11 % (9) |
| PPO, W2에서 학습한 정책을 그대로 적용(전이) | 12 % (17) | 12 % (7) | — |
| 오라클(소스 위치를 앎, 검증용) | 51 % (60) | 62 % (53) | 61 % (50) |

- 95 % 구간은 ±5~7 %p(n = 120), 홀드아웃은 ±13 %p(n = 30). PPO는 시드 1개(W0·W1), W2는 3시드.

## 3. 읽는 법
1. **PF 자체는 바람장을 몰라도 된다.** 건물 지도 + 바람 1점(W1)이면 소스 위치를 아는 경로(오라클)에서 62 %로 CFD 바람(61 %)과 같다. W0에서 잃는 소스(101·113·104: 플룸이 소스 풍상에 있거나 국소 풍향이 40° 이상 틀어진 곳)가 W1에서 모두 회복된다.
2. **탐색 방법의 격차는 바람장이 아니라 경로에 있다.** greedy-MAP·Infotaxis는 세 수준에서 8~12.5 %로 구간이 겹친다.
3. **PPO는 상세 바람장 없이 학습·평가해도 동작하지만, 기준 방법을 넘는다고는 말할 수 없다.** W0 시드 1은 15 %로 같은 조건의 greedy-MAP 9 %·Infotaxis 11 %보다 점추정이 높았지만(짝지은 비교 12:5, 9:4; p = 0.14, 0.27) 시드 2는 6 %였고, W1 시드 1은 7 %로 greedy·Infotaxis 8 %와 같다(6:8, 7:9). 시드 간 변동(W0 6~15 %, W2 8~14 %)이 수준 간 차이만큼 크므로 결론은 "세 수준 모두에서 신념 기반 기준 방법과 같은 수준, lawnmower·random보다 높음"이다. W2에서 학습한 정책을 W0·W1에 그대로 써도 각각 12 %로 동작한다(정책이 바람 수준을 넘어 전이).
4. 전체 성공률이 낮은 이유: 훈련 소스 5개(102·104·106·107·112)에서 탐색 방법은 모두 0~4 %다. 그중 102·104·112는 오라클이 80~100 % 찾으므로 신호는 있지만 멀리서는 탐지되지 않는 정체 소스(경로 문제)이고, 103·106·107은 오라클도 0 %라 15 m 고도에서는 관측이 안 되는 소스다(센서 고도·측정 시간의 한계). 열린 소스 4개(108·111·112·113)만 보면 PPO W0 28 %, greedy-MAP 15 %, 오라클 50~75 %다.

## 4. 한계와 솔직한 주의
- W1 포텐셜 유동은 후류·재순환이 없어 CFD에서 역류하는 소스(101·102)와 안뜰(106·107·110)을 표현하지 못한다. 그래도 PF 결과(오라클)는 W2와 같았다.
- 기준 바람 1.68 m/s(+x)는 참고 시뮬레이션의 도심 10~15 m 평균에서 가져왔다. 현장이라면 기상 관측 1점으로 대체되며, PF가 소스 강도를 주변화하므로 풍속 절대값보다 풍향이 중요하다. 풍향 ±10° 민감도는 아직 안 했다.
- PPO W0·W1은 시드 1개다(W2는 3시드: 훈련 소스 13.3 / 8.9 / 12.2 %). W1 사슬은 학습 분포에서도 가장 낮게 끝났다(단계 B2 28 % 대 W0 31 %, W2 34 %) — 시드 추가 전에는 W1 정책이 나쁘다고 단정하지 않는다.
- ROM(B안의 본래 형태)은 여러 풍향·풍속의 CFD 스냅샷이 필요한데 현재 계산은 풍향 1개 1건뿐이라 이번 발표에서는 다루지 않는다(향후 연구로 기술).

## 5. 확인·요청 사항
- 데이터가 SPH 해석인지 LBM인지: 9/29에 전달받은 코드 소유자 답변은 LBM이었고 파일은 2.5 m 정규 격자다. 김도현 박사님께 직접 확인한 뒤 용어를 정정하겠다.
- 다른 풍향·풍속의 계산이 있는지(있으면 ROM·풍향 민감도가 열린다).

## 6. ICRS-15까지 계획 (10/19 제출)
- 10/4~5: PPO W0·W1 시드 2·3, 풍향 ±10° 민감도(기준 방법), 1대 비교.
- 10/6~8: 새 시드 에피소드(소스당 30개)로 최종 평가, 그림·3D 영상, 표 확정.
- 10/9~18: 발표 자료.
