# 면담 메모 — 상세 바람장 없이 드론 선원 추정이 되는가 (2026-10-03, 지희)

## 1. 지적 사항과 대응
- 지적: 상세 CFD 바람장을 PF에 직접 쓰는 방식은 바람장을 안다고 가정한 것이고, 현장에서는 며칠짜리 계산을 할 수 없다. (A) 상세 유동장 없이 푸는 방법 또는 (B) 제한된 정보로 상세 유동장을 빠르게 추정하는 방법이 필요.
- 대응: 추정기(PF 전방모델 + 정책 관측의 바람)에 주는 바람 정보를 세 수준으로 두고, **같은 파이프라인·같은 130 에피소드(시작 위치·소스·시간 동일)** 로 비교했다. 진실 데이터(LDM 입자), 성공 판정(σ < 30 m, 오차 < 50 m), 보상, 기준 방법 정의는 그대로다.

| 수준 | 현장에서 필요한 정보 | 전방모델 | 계산 |
|---|---|---|---|
| W0 | 기준 바람 1점(풍속·풍향) | 균일 바람 + 가우시안 플룸 (A안) | 즉시 |
| W1 | 기준 바람 1점 + 건물 지도(GIS) | 건물 주위 질량 보존 포텐셜 유동 → 이류–확산 adjoint (B안의 가장 가벼운 형태; 진단 바람 모델 QUIC-URB·QES-Winds·URock 계열의 단순화) | 1~2 s |
| W2 | 상세 CFD 바람장 | 기존 adjoint (참고 상한) | 며칠 |

## 2. 결과 — 최종 평가 (2026-10-04, 새 에피소드 390개: 13개 소스 × 30, 2대, 시간 변화 플룸; 세 수준이 같은 에피소드; 기준 방법 1회, PPO는 수준별 3시드 합산)

관측 가능 12개 소스(360 에피소드, PPO 1,080); 괄호는 학습에 쓰지 않은 홀드아웃 3개 소스(90, PPO 270).

| 방법 | W0 평균 바람 | W1 평균 바람 + 건물 지도 | W2 CFD 바람 |
|---|---|---|---|
| random | 1 % (0) | 0 % (0) | 0 % (0) |
| lawnmower | 1 % (1) | 1 % (0) | 1 % (0) |
| greedy-MAP | 12.5 % (17) | 9.2 % (8) | 7.8 % (10) |
| GMM-Infotaxis | 10.3 % (13) | 9.2 % (8) | 9.2 % (12) |
| **PPO (제안, 해당 수준에서 학습, 3시드 합산)** | **13.5 % (26)** | **6.0 % (5)** | **7.9 % (7)** |
| 오라클(소스 위치를 앎, 검증용) | 47 % (52) | 54 % (38) | 52 % (33) |

- 95 % 구간: 기준 방법 ±3~4 %p(n = 360), PPO ±2 %p(n = 1,080); 홀드아웃 ±7 %p / ±5 %p.
- 개발 단계의 130 에피소드 결과(같은 방향)는 `srcloc_env/docs/wind_knowledge_levels.md` 5장에 있다.

## 3. 읽는 법
1. **PF 자체는 바람장을 몰라도 된다.** 건물 지도 + 바람 1점(W1)이면 소스 위치를 아는 경로(오라클)에서 62 %로 CFD 바람(61 %)과 같다. W0에서 잃는 소스(101·113·104: 플룸이 소스 풍상에 있거나 국소 풍향이 40° 이상 틀어진 곳)가 W1에서 모두 회복된다.
2. **탐색 방법의 격차는 바람장이 아니라 경로에 있다.** greedy-MAP·Infotaxis는 세 수준에서 8~12.5 %로 구간이 겹친다.
3. **PPO는 상세 바람장 없이 학습·평가해도 동작하고, 전체 성공률은 기준 방법과 같은 수준이다.** W0 13.5 % 대 greedy-MAP 12.5 %·Infotaxis 10.3 %, W2 7.9 % 대 7.8·9.2 %(구간 겹침); W1에서는 6.0 %로 기준 방법 9.2 %보다 낮다(원인 미해결, 세 시드 공통). **학습에 쓰지 않은 소스에서는 W0 정책이 기준 방법보다 분명히 높다**: 26 % 대 17·13 %(같은 에피소드 짝지은 부호 검정 p ≤ 0.002, 세 시드 모두 18~33 %; 소스 103은 기준 방법 0/30, PPO 20/90). W2 정책에는 이 효과가 없다(7 % 대 10~12 %). 가설: 관측에 상세 바람 항목이 없는 W0에서 정책이 신념 기하에 더 의존해 학습 소스 특화가 덜하다 — 발표에서는 재현된 관찰로 제시하고 원인은 가설로 둔다.
4. 전체 성공률이 낮은 이유: 소스 101·102·104·106·107은 어느 방법도 0~1 %다(홀드아웃 아님). 그중 102·104는 오라클이 찾으므로(각 수준 80~100 %) 신호는 있지만 멀리서 탐지되지 않는 정체 소스(경로 문제)이고, 106·107·110은 오라클도 0 %라 15 m 고도에서 관측이 안 되는 소스다. 열린 소스 108·109·111에서는 PPO-W0가 30~38 %, greedy 23~37 %, 오라클 70~90 %다.

## 4. 한계와 솔직한 주의
- W1 포텐셜 유동은 후류·재순환이 없어 CFD에서 역류하는 소스(101·102)와 안뜰(106·107·110)을 표현하지 못한다. 그래도 PF 결과(오라클)는 W2와 같았다.
- 기준 바람 1.68 m/s(+x)는 참고 시뮬레이션의 도심 10~15 m 평균에서 가져왔다. 민감도(130 에피소드): 풍향 ±10°는 어느 수준에서도 구간 안(오라클 W0 51 → 47·48 %, W1 62 → 57·60 %); 풍속은 W0 플룸에서 크게 작용(×0.5 58 %, ×2 38 % — 느리게 잡는 쪽이 안전)하고 W1은 둔감(56~62 %).
- 기준 방법은 결정론적이라 1회, PPO는 3시드다. W1 정책이 약한 원인은 critic 학습 문제로 확인됐다: 학습 때 critic에만 소스 진실을 주는 '진실 critic'(평가 조건 불변)으로 3시드 모두 기준 방법 수준(9.6 % 대 greedy 9.2 %)까지 회복한다(원래 6.0 %, 같은 시드 짝지은 검정 p < 0.001). 보상 shaping·가치 정규화는 효과가 없었다. 반대로 W0에서는 진실 critic이 홀드아웃 일반화를 떨어뜨린다(26 → 18 %, p = 0.007) — 신념만 보는 학습이 새 소스 일반화에 유리하다는 해석과 일치한다. 발표 표는 보조 기법 없는 정책으로 통일하고, W1 진실 critic은 절제 실험으로 한 줄 넣는다. 1대 결과: 모든 방법이 2대의 절반 이하(오라클 32~40 %), PPO 1대 2~6 %.
- ROM(B안의 본래 형태)은 여러 풍향·풍속의 CFD 스냅샷이 필요한데 현재 계산은 풍향 1개 1건뿐이라 이번 발표에서는 다루지 않는다(향후 연구로 기술).

## 5. 확인·요청 사항
- 데이터가 SPH 해석인지 SPH인지: 9/29에 전달받은 코드 소유자 답변은 SPH이었고 파일은 2.5 m 정규 격자다. 김도현 박사님께 직접 확인한 뒤 용어를 정정하겠다.
- 다른 풍향·풍속의 계산이 있는지(있으면 ROM·풍향 민감도가 열린다).
